# Fundamentos Java - Método
Uma série de exercícios simples de treinamento fundamental em Java para aperfeiçoamento de práticas de método.

# <u>Divisores de um número (DivisoresDeUmNumero)</u>

- O programa JAVA lê um valor inteiro e positivo (possui validação de entrada). Imprime todos os seus divisores
inteiros, positivos e negativos. A leitura fica no main(); a impressão dos
divisores, em um método.
